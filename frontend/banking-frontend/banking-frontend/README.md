# Banking Management System - Frontend

## Technology
- React
- JavaScript
- HTML
- CSS
- Vite

## Requirements
- Node.js 18+ recommended
- Backend must be running on port 8080

## Run

Open this folder in VS Code terminal:

```bash
npm install
npm run dev
```

Open:
`http://localhost:5173`

Demo login:
- Username: `admin`
- Password: `admin123`

## Backend URL
The React app calls:
`http://localhost:8080/api`

If you change the Spring Boot port, update `src/api.js`.

## Main screens
- Dashboard
- Customers
- Accounts
- Deposit
- Withdrawal
- Transfer
- Transaction history
